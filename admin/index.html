Import rules

Automatic category creation · duplicate checks · required-field validation · image matching · auto-publish.

Duplicates are detected against the existing catalog and within your import by normalized product name + category. Duplicate rows are skipped, not overwritten. Invalid rows are skipped and listed in the preview.
Important: this current site stores products in this browser's localStorage. Bulk upload works here and appears in the storefront in the same browser, but it is not cloud-persistent or shared across devices yet. True persistent cloud storage requires a configured database and image bucket; this upload tool will not pretend that local storage is cloud storage.
